# Hiba Ayoub Portfolio
React + TypeScript + Vite, React Three Fiber (hero), Recharts (charts).

    npm install
    npm run dev      # local dev server
    npm run build    # type-check and production build into dist/

- Content lives in `src/data.ts`. All copy comes from the CV; chart values are illustrative.
- The CV button uses `public/Hiba_Ayoub_Frontend_Developer.pdf`.
- The contact form opens the visitor's email app (mailto). Connect an email service if you want direct sending.
